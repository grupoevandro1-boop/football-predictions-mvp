# GoalPredict

Aplicativo de prognósticos de futebol e palpites com visualização de partidas, odds e boletim de apostas.

## Como executar

### Opção 1: abrir diretamente

Abra o arquivo `index.html` no navegador.

### Opção 2: servir localmente

```bash
cd /caminho/para/o/projeto
python3 -m http.server 8000
```

Em seguida, acesse:

```text
http://localhost:8000
```

## Funcionalidades

- Lista de jogos com odds e probabilidade
- Selecção de palpite por partida
- Boletim com retorno estimado
- Estatísticas de precisão e lucro
- Modo de palpites recomendados para ajudar na decisão

## Estrutura

- `index.html` — layout principal
- `styles.css` — estilos visuais
- `app.js` — dados e lógica da aplicação
